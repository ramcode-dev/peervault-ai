# Humanizer

Use this skill for Rewrite or edit text to sound natural, specific, and suited to its audience while keeping the author’s meaning.

## Simple workflow

1. Identify audience, purpose, and the voice to preserve.
2. Replace vague claims and stock phrases with concrete language; vary sentence rhythm naturally.
3. Keep facts, intent, and important nuance intact. Do not add claims or make the voice artificially casual.
4. Return the finished text first; explain edits only when useful.

## Response style

Lead with the useful answer or result. Match the user’s requested depth, keep routine work short, and explain only the decisions or limits that help them move forward.
