How E2EE Works

1
Key Generation
On page load, an ECDH P-256 key pair is generated locally using Web Crypto API. Only the public key is ever shared.
2
Key Exchange
After WebRTC DataChannel opens, peers exchange their ECDH public keys over the secure channel.
3
Shared Key Derivation
Each peer independently derives the same AES-GCM-256 shared secret via ECDH. No secret ever transits the network.
4
Encrypted Transfer
Every 64 KB file chunk is encrypted with AES-GCM-256 using a random 12-byte IV prepended to the ciphertext.
